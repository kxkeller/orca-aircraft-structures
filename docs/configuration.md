# Aircraft Structures plugin configuration

GENERATED by `python tools/config.py docs` from `aircraft_core/config_schema.py` -- do not hand-edit; edit the schema and regenerate.

Every key the plugin's stored `cap_config` accepts. An unknown key is an error, not silence -- see `tools/config.py check`.

This CLI fails closed on an unknown top-level key. The running plugin does not: a top-level `cap_config` key is round-tripped by the host itself, and no reachable source rules out the host ever adding one of its own, so the running plugin only warns loudly (the same message, on the slice's host-log result line and in its diagnostics JSON) and keeps using the default for that key -- see `plugin/aircraft_structures/capability.py`'s `_unknown_top_level_key_warning` docstring for the full reasoning. An unknown key inside a `families` entry IS fail-closed everywhere, including the running plugin, since that data is unambiguously this plugin's own.

Each entry of the top-level `families` list accepts only these keys. `families` empty (the default) reproduces the single-implicit-family behaviour built from the top-level fields above.

## Cross-field rules

- Exactly one of `gap_ratio` / `slot_gap_mm` must be set, at the top level and independently on each family (the other left `null`, or both left `null` on a family to inherit the spec's own gap mode).
- `z_period_mm` requires `z_drift_mm_per_mm` to also be set, at the top level and independently on each family.
- `skin_margin_mm` must exceed `2 * ` the resolved outer wall line width -- load-bearing for the no-sever proof. A config that violates this is refused before any layer is generated.

## Tooling

- `python tools/config.py list` -- tracked configs in `presets/plugin/`.
- `python tools/config.py show` -- the live config, labelled.
- `python tools/config.py use <name>` -- install a tracked config, validated first.
- `python tools/config.py check` -- validate the live config.
- `python tools/config.py set <key> <value>` -- change one value, validated, preserving everything else. Dotted `families.<name>.<key>` reaches into a family by name.
